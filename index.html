APPLICATION DE BUREAU · PYTHON / PYQT5

AutoHealingSystem

Suite de supervision et d'auto-réparation pour Windows : plus de 55 vérifications automatiques (services, réseau, disque, pilotes, pilotes d'affichage, audio, USB...) et réparation en un clic — SFC/DISM, réinitialisation réseau, Windows Update, Office, WMI, cache des polices, index de recherche. Interface à onglets (tableau de bord, réseau, performances, système, outils) en thème sombre, alertes e-mail et sonores, empaquetée en application Windows autonome. Base de code passée de 9 000 à plus de 16 000 lignes lors de la migration complète vers PyQt5.
